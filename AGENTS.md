# tag.bet — заметки для агентов

- Сайт на Next.js 16 (App Router, previous caching model — без `cacheComponents`), Tailwind v4, TypeScript 7.
- Все данные — через `lib/data.ts` (кэш `lib/cache.ts` + лимитер `lib/rate-limit.ts`). Не вызывайте `apiGet` из страниц напрямую: у SStats лимит 30 запросов/мин без ключа.
- Страницы с данными — `dynamic = 'force-dynamic'`; кэширует наш слой данных, а не Next.
- У динамических страниц нет `loading.tsx` намеренно: иначе `notFound()`/`permanentRedirect()` отдают 200 вместо 404/308.
- Цветовой токен фона называется `ink` (не `base`: в Tailwind v4 `text-base` — размер шрифта).
- Партнёрские ссылки — только через `goHref()` → `/go/[slug]` (учёт кликов + subid) и `CtaLink` (rel=sponsored).
- Тексты — по-русски; названия команд в текстах только в именительном падеже («команда «X»»).
- Демо без сети: `SSTATS_MOCK=1` (полосы над шапкой нет — только строка в подвале, `IS_MOCK` в `Footer.tsx`). Проверки: `npm run typecheck`, `npm test`, `npm run build`.
- «Матч в слайдах» (сторис): данные — `lib/story.ts` → `/api/story/[id]`, просмотр и графики — `components/story/`. Ссылки на матч в списках — через `StoryLink` (обычная ссылка для SEO, клик открывает сторис).
- Кружки историй на главной: группы — `lib/story-groups.ts` (порядок по `lib/rank.ts`), ряд — `components/story/StoryCircles.tsx`, очередь передаётся в просмотрщик через `openStory({ queue })`. Просмотренные — в `localStorage` (`components/story/seen.ts`, ключ `tagbet:seen:v2`), только для колец и отдельно для каждого кружка (отметка «кружок:матч»): просмотр в одном кружке не гасит другие, открытия из списков и виджетов не считаются; сегменты гаснут по порядку от верха. Очередь по тапу и отметки повторов — `components/story/queue.ts` (тест `tests/story-queue.test.ts`). На главной — «#в игре», «#топ дня» и до 5 главных тегов (`mainCircles`), подписи в одну строку; хештег — у всех кружков, и у подборок тоже (владельцу показалось странным, что «Топ дня» без него).
- «Сводка дня» (виджеты первого экрана главной): данные — `lib/day-summary.ts` (`buildDaySummary`: матч дня и подборки `lists` — live, ближайшие, фавориты от 60%, голы, выгодные, падение кэфа; матч дня в подборках не повторяется; `summaryCards` — какие 4 плитки показать: что идёт (или скоро начнётся) → фавориты → голы → выгодно, запасные — кэф упал, ближайшие, турниры дня), вид — `components/DaySummary.tsx`. «Матч дня» — `components/TopCarousel.tsx` (клиент): по слайду на главный матч каждой топ-лиги (`tops` в `buildDaySummary`, до 5, первым — матч дня); лига выбирается чипом-меню «Ла Лига ▾» справа сверху, сама карточка не листается (выбор не должен уезжать); лента со scroll-snap — свайп на телефоне, без JS видны все слайды. «Проверка шансов · за месяц» (`ChanceTile` в `DaySummary.tsx`, только на «Сегодня»): сбываются ли проценты сайта — той же формы, что остальные плитки: «58% — сбылось там, где давали 60%» (корзина «около 60%», порог #фаворит), «в среднем ±1,5 пункта», «2 506 исходов за месяц», внизу полоска «сбылось» с белой чертой «давали»; «→» ведёт на `/about#proverka`, где полный график «давали — сбылось» по корзинам «около 10% … 90%» (`components/ChanceChart.tsx`: столбик — сбылось, белая черта — давали, монохромно, подсказка при наведении/тапе/стрелках). Расчёт — `lib/chance-check.ts` (исходы 1X2 сыгранных «взрослых» матчей, шансы — кэфы перед матчем без маржи, итог — по основному времени; корзина меньше 30 исходов не показывается, всего меньше 300 — плитки нет), данные — `getChanceCheck` в `lib/data.ts` (30 дней до сегодня; итоги дня кэшируются отдельно и надолго, на холодном старте главная и `/about` ждут `peekChanceCheck` не дольше 1,5 с, остальное считает прогрев). Не возвращайте виджет «сколько бы заработали» в рублях: крупное «+8 160 ₽, если ставить по 1000 ₽» читается как «ставки — заработок» (ст. 27 закона «О рекламе»), владелец выбрал проценты; и «Фавориты вчера» (кто выиграл, без сравнения с шансом) — тоже нет. Расстановка: сверху во всю ширину «Матч дня», под ним ряд из четырёх плиток-цифр одной высоты: «Фаворит дня», «Ждём голов», «Кэф упал» и «Проверка шансов» (в другие дни вместо неё — «Выгодно»; «Выгодно» же занимает место плитки, для которой нет матча); на планшете по две в ряд, на телефоне столбиком. Владелец сравнил с вариантом «высокий «Матч дня» слева, плитки справа» и решил, что ряд под широкой карточкой спокойнее и понятнее — не возвращайте эту схему. «Матч дня» — как карточка матча в спортивных приложениях; на компьютере в две колонки, без пустой середины: слева табло «хозяева (эмблема 48px и название) · время (под ним «через 40 мин» / дата; в игре — красный счёт и минута) · гости» — названия заметнее времени — и под ним «Разбор за минуту» и «Выгодно», справа через тонкий разделитель — вывод словами, нейтральная полоса шансов в процентах (светлая часть — фаворит) с подписями исходов прямо под ней «хозяева · ничья · гости» (полоса не под табло, поэтому без подписей непонятно, где кто) и факты «почему» из тегов одной вложенной панелью (значки — как у кружков этих тегов; сколько — по высоте окна: от 740px один, от 800px два, от 900px три); во время игры справа — полоса «сыграно N из 90 минут». Высота карусели — по самому высокому слайду. Плитки — крупная цифра по одному матчу (`StatTile`; какой матч — `dayStats` в `lib/day-summary.ts`: только ещё не начавшиеся, без матча дня, по возможности разные, лучше повтор, чем пустая плитка): заголовок с вопросом и источником («Фаворит дня · по кэфам», «Кэф упал · с открытия линии») и стрелка `Go` на подборку (страницу тега); цифра (лайм — выгодно, янтарь — кэф упал, остальные — белые) и рядом простыми словами, что она значит («на победу «Наполи»», «шанс 3+ голов», «кэф на победу «Балтика»»); полный матч (выделенная команда — ярче или цветом плитки), «время · турнир»; внизу — полоска «сколько из 100» или «было 2.32 → стало 1.94» / «честный 3.18 → платят 3.54». Цифра и матч ведут на разбор матча, заголовок — на подборку; вложенных ссылок нет. «Ждём голов» — шанс 3+ голов из тега, а без тега — из пары кэфов «больше/меньше 2.5» без маржи, от 50%. История: «одна цифра + один матч» с подписями «к честной цене», «с открытия линии» и плиткой «Первый матч 14:30» владелец счёл неинформативной, списки по 3 матча в плитках — каталогом; понравилось «большие цифры или график». Не возвращайте ни списки в плитках (все матчи — ниже, по прокрутке), ни цифры без простых слов рядом, и не убирайте «Матч дня» — без него сводка («Главное за день») не понравилась. Всё тёмное, цвет — только у цифр и выделенной команды: лайм — выгодно, янтарь — кэф упал, красный — live; текст не мельче 13px, без колец-диаграмм (похожи на значок загрузки). Выбор дня — `DateTabs` (Вчера · Сегодня · Завтра · дальше день недели без числа; красная точка у «Сегодня», пока идут матчи — `liveToday` из `DayView`) + календарь `DatePicker` (±1 год / +2 месяца). Порядок «Все матчи дня» — переключатель «По турнирам / По времени» ссылками `?sort=time` (без JS, canonical прежний; `TimeBlock` — по часам, с турниром в строке); на прошедших днях переключателя нет — там порядок по турнирам, главные результаты первыми. Первый экран главной (шапка, кружки, сводка) на компьютере занимает всё окно: обёртка в `DayView` — `lg:min-h-[min(calc(100svh-7rem),50rem)]`, сводка — `lg:flex-1` и внутри flex-колонка: ряд плиток — по содержимому (≈180–190px; на невысоком экране отступы плиток меньше), вся лишняя высота — «Матчу дня» (`lg:flex-1`; не делайте строки grid с `fr` — в intrinsic-проходе они раздуваются), команды и вывод растут с высотой окна (`clamp(…vh…)`), а «Все матчи дня» начинаются ниже, по прокрутке. Сводка должна влезать целиком в 1280×720 и 1440×760, а заголовок «Матчи» — не выглядывать снизу; проверяйте замером. На прошедших днях сводки нет.
- Шапка (логотип — только наклонная лаймовая решётка `LogoMark`, 26 px в шапке и 28 в подвале, без надписи «tag.bet» — так решил владелец; знак — `components/logo-paths.ts` из `public/brand/mark.svg`; без подложки): `components/Header.tsx` + `HeaderShell.tsx` (стекло после прокрутки) + `NavCapsule.tsx` (меню-капсула; раздел по адресу — `activeNav`).
- Кнопки и чипы внутри карточек (чип лиги, стрелка `Go`, «Разбор за минуту», «Выгодно») — скруглённые прямоугольники (углы 9–10px, меню — 14px), мягкая заливка без обводки, высота 28px; капсулой остаётся только меню в шапке. Отступ карточек сводки — 18px со всех сторон (у чипа в углу сверху и справа поровну — проверяйте замером).
- Цвета по смыслу: лайм — «цена выше честной» (сила перевеса — яркостью лайма, `edgeTone` в `components/Flaps.tsx`), янтарь — прогруз, красный — live. Светофор не используем.
- Для тех, кто не разбирается в цифрах: вывод словами — `lib/verdict.ts` (`buildVerdict`: «Скорее выиграет «X»», голы, падение кэфа, выгодная ставка; `split100` — проценты трёх исходов в сумме ровно 100, `outcomeText`/`outcomeShort` — исход словами вместо «П1»/«ТБ 2.5»). Только факты из данных: про прогруз — «кэф снизился», не «массово ставят». Пороги слов — как у тега #фаворит (60%) и слайда «Кто фаворит» (47%). Без обещаний: только «скорее», «вероятно». В строках и «Матче дня» — только выгодная ставка (обычный прогноз модели бывает «против» вывода). Теги подписаны простыми словами (`label`: `#выгодно`, `#кэф упал`…), slug и адреса прежние; цифра тега — в `TagHit.p`, а не в тексте.
- Обложки кружков историй: плоские, как карточки — заливка `CIRCLE_BG` (= `--color-panel`), тонкая рамка `ring-edge`, светлая иконка тега без теней, бликов и зерна (владелец счёл «стеклянный» вид чужим); кружка «Все теги» нет — в ряду только истории, «Теги» есть в шапке. Иконка тега — `lib/story-art.ts` + `components/story/ArtIcon.tsx` (цвет — только в кольце: лайм не смотрели, красный LIVE, серый просмотрено; цвета тегов `ART` — только для фона просмотрщика). Кольцо (`Ring` в `StoryCircles.tsx`): все сегменты одной толщины 2.5px по радиусу 32, просмотренные — `--color-mute`; не делайте их тоньше или бледнее — кольцо из толстых и тонких дуг владельцу показалось кривым. Фокус с клавиатуры — белый круг вокруг кружка (не рамка вокруг кружка с подписью); у ряда `pt-1.5`, иначе прокрутка ряда срезает этот круг сверху; своя картинка — файл `public/stories/<ключ>.*` (`lib/story-covers.ts`, только сервер). Цифр в кружках нет.
