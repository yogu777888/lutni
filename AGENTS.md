# tag.bet — заметки для агентов

- Сайт на Next.js 16 (App Router, previous caching model — без `cacheComponents`), Tailwind v4, TypeScript 7.
- Все данные — через `lib/data.ts` (кэш `lib/cache.ts` + лимитер `lib/rate-limit.ts`). Не вызывайте `apiGet` из страниц напрямую: у SStats лимит 30 запросов/мин без ключа.
- Страницы с данными — `dynamic = 'force-dynamic'`; кэширует наш слой данных, а не Next.
- У динамических страниц нет `loading.tsx` намеренно: иначе `notFound()`/`permanentRedirect()` отдают 200 вместо 404/308.
- Цветовой токен фона называется `ink` (не `base`: в Tailwind v4 `text-base` — размер шрифта); сейчас `ink` — графит (текст на белых кнопках, стекло шапки), а фон страницы — голубой градиент на `body`.
- Цветовая система (владелец выбрал ярко-голубую версию вместе с ChatGPT): фон страницы — градиент `#119AF5 → #0C84E4`, текст на нём белый; карточки светлые (`#F7FBFF`, вторичный `#EAF4FF`, рамка `rgb(17 22 29/.08)`, тень `0 10px 30px rgb(8 25 46/.08)` — `.card` и `.surface`), текст в них графитовый (`#0F1722`, вторичный `#617184`); меню-капсула, карточка «Главных матчей», сторис и цифры-«флапы» — графитовые острова (`.on-dark`: `#11161D`/`#1A222C`/`#2A3441`). Всё — в `app/globals.css`: токены на `:root` — для текста на голубом, а внутри `.card` и элементов с `bg-panel*` (селектор по классу) те же имена (`fg`, `dim`, `mute`, `edge`, `white`, `btn`, `good`, `hot`, `live`…) переопределены под светлый фон, внутри `.on-dark` — под графит; компоненты пишут `text-fg`/`text-dim`/`bg-white/[0.04]` и не знают, где стоят (`bg-white/[…]` в светлой карточке — графитовая плашка). Кнопки — `bg-btn text-btn-ink hover:bg-btn-hover`: на голубом белая с графитовым текстом, в карточке голубая. «Выгодно» текстом — `text-good` (в карточке тёмно-зелёный: лайм на светлом не читается), лаймовые плашки (`bg-acid`) и «флапы» — лайм. Контраст: белый мелкий текст на голубом — около 3:1 (AA только для крупного), голубая кнопка с белым текстом — 3–3,9:1; если нужен строгий AA — темнее голубой.
- Цветовые версии (эксперимент владельца, сформулирован с ChatGPT): по умолчанию — светлая голубовато-серая: меню — светлая полупрозрачная капсула на голубом, как переключатель iOS (белые пункты, выбранный — белая «таблетка» с тёмным текстом; графитовое `#1E2A36` владельцу не понравилось — «чёрное»), шапка после прокрутки — голубое стекло, карточка «Главных матчей» светлая (градиент `#EEF6FB → #E3EEF8`, текст `#18222D`/`#5D6C7B`, кнопка «Разбор матча» графитовая, половины карточки мягко окрашены цветами клубов, как в Apple Sports (`.hero-tint` в `Paint`: радиальные пятна 32% цвета хозяев слева и гостей справа, к центру сходят на нет; цвета — `matchColors` из `lib/team-colors.ts`, `DayView` ждёт их не дольше 1,5 с, нет цвета — без подкраски; владелец просил заполнить пустое светлое пространство), эмблемы на фоне — только силуэт одним ровным тоном, как водяной знак: у каждой эмблемы свой SVG-фильтр (`Mark` в `TopCarousel.tsx`, id через `useId`) — форма по прозрачности, сглаженный край, заливка тёмным оттенком цвета клуба (`darken`: светлота ×0,75; нет цвета — графит), 10%; не CSS-маска: маска грузит картинку с CORS, и настоящие эмблемы с чужого сервера пропадают (в демо они data:-адреса — там не видно); нет цвета — графит), 10% — так попросил владелец вместо графитовых «теней»; в графитовой версии — прежнее тиснение картинкой; любые детали маленькой эмблемы при увеличении в 3–4 раза дают пиксели, рябь или пятна — серую печать, контур «как рисунок» и «три тона серого» владелец забраковал: «уродство»), истории светлые (`#E6F2FA → #D7E7F3`, рамки прежние), карточки — `#F3F8FC`/`#EAF3FA`, рамка `rgb(24 34 45/.08)`. Прежняя графитовая — `html[data-look='dark']`: `?look=dark` (запоминается в localStorage `tb-look`), `?look=light` — обратно; скрипт в `<head>` `app/layout.tsx` ставит атрибут до отрисовки. Цвета — в блоке «Цветовые версии» `app/globals.css` (классы `.hero`, `.hero-scrim`, `.hero-mark`, `.story-cover`, `.nav-capsule`; `Paint` берёт `--paint-1…4`). Когда владелец выберет — оставить одну версию и убрать скрипт. Описание ниже местами про прежнюю графитовую.
- Партнёрские ссылки — только через `goHref()` → `/go/[slug]` (учёт кликов + subid) и `CtaLink` (rel=sponsored).
- Тексты — по-русски; названия команд в текстах только в именительном падеже («команда «X»»).
- Демо без сети: `SSTATS_MOCK=1` (полосы над шапкой нет — только строка в подвале, `IS_MOCK` в `Footer.tsx`). Часы в демо стоят (всегда 4 октября 2026-го, 19:30 МСК; `SSTATS_MOCK=design` — то же самое): один и тот же день во всех состояниях, прогрев разбирает все матчи топ-лиг (и идущие — для графика «Форма»); так попросил владелец, пока идёт работа над виджетами. `SSTATS_MOCK_NOW` «переводит» часы демо — дальше время идёт. Часы сайта — только `appNow()` из `lib/format.ts` (их же берёт демо), не `Date.now()` там, где речь о времени матчей. Кэш демо на диск не пишется (`lib/cache.ts`), иначе старые данные без эмблем живут часами. Эмблемы в демо — `.data/team-logos.json` от `npm run team-logos` (`scripts/team-logos.mjs`: команды демо-лиг из `/Teams/list` по странам, ~11 запросов; читает `lib/sstats/team-logos.ts`, файл перечитывается при изменении); без файла — монограммы и подсказка в подвале. Проверки: `npm run typecheck`, `npm test`, `npm run build`.
- «Матч в слайдах» (сторис): данные — `lib/story.ts` → `/api/story/[id]`, просмотр и графики — `components/story/`. Ссылки на матч в списках — через `StoryLink` (обычная ссылка для SEO, клик открывает сторис).
- Кружки историй на главной: группы — `lib/story-groups.ts` (порядок по `lib/rank.ts`), ряд — `components/story/StoryCircles.tsx`, очередь передаётся в просмотрщик через `openStory({ queue })`. Просмотренные — в `localStorage` (`components/story/seen.ts`, ключ `tagbet:seen:v2`), только для колец и отдельно для каждого кружка (отметка «кружок:матч»): просмотр в одном кружке не гасит другие, открытия из списков и виджетов не считаются; сегменты гаснут по порядку от верха. Очередь по тапу и отметки повторов — `components/story/queue.ts` (тест `tests/story-queue.test.ts`). На главной — «В игре», «Топ дня» и до 5 главных тегов (`mainCircles`), подписи в одну строку, без решётки и с большой буквы («Кэф упал», «50 на 50» — `storyLabel` в `lib/story-groups.ts`), так же — в шапке просмотрщика; так решил владелец (раньше решётка была у всех кружков). У тегов в строках матчей, на страницах тегов и внутри слайдов решётка остаётся.
- «Сводка дня» (первый экран страницы дня — сегодня, в прошедшие и будущие дни): данные — `lib/day-summary.ts` (`mainMatches`, `dayCounts`, `goalsPicks`, `linePicks`, `moveExample`) и `lib/lines.ts`, вид — `components/DaySummary.tsx` + `components/TopCarousel.tsx` (клиент). Схема — по заданию владельца (сформулировано вместе с ChatGPT): понятный главный матч и разные по назначению способы просмотра — истории (короткий просмотр матчей) и подборки (полные страницы дня со сравнением и фильтрами).
  - «Главные матчи»: до 5 встреч (`mainMatches`: по важности турнира и команд — `prestige`, сначала по одной на лигу; идущие и предстоящие важнее сыгранных, на прошедших днях — итоги; молодёжные, женские, перенесённые — мимо), стрелки в шапке (на телефоне их нет — там свайп), без автопрокрутки; сколько матчей и какой на экране — полоски-точки, как в баннерах App Store: внизу по центру, в нижнем отступе карточки (высоту не меняют — первый экран влезает как раньше), на телефоне — справа от «Разбора за минуту», крупнее под палец (стрелки там не влезали в ряд); клик — к матчу, подсказка с командами (`MainSlide.title`); «Матч 3 из 5» — только для экранного диктора; лента со scroll-snap, без JS видны все матчи, высота — по самому высокому слайду. Шапка: слева турнир и тур (красная точка — идёт), справа стрелки и чип дня, в углу сверху и справа поровну. Чип дня — переход на страницу дня («Вчера · Сегодня · Завтра», `dayHref`): выбранный день меняет всю страницу согласованно (блок, подборки, список) и уходит в ссылки подборок; раньше чип менял только блок — владелец передумал.
  - Слайд — табло по центру, как в Apple Sports (`MatchSlide` в `DaySummary.tsx`): эмблема на матовом светлом круге и название под ней — хозяева слева, гости справа, в середине «Начало 21:00 мск» / счёт и минута (LIVE — красная точка) / «итог» и под ними светлая «Разбор матча» (тёплый белый, как текст; на компьютере — подпись в слайде: вся карточка — ссылка на сторис; на телефоне — кнопка «Разбор за минуту» под лентой рядом с полосками-точками); проигравший тусклее; на телефоне длинное название мельче (`phoneSize`: «Саутгемптон» — 15px, слово от 12 букв — 13px), а не перенос по букве. «Выгодно» в блоке нет — выгодные ставки в таблице ниже.
  - Под табло до начала — тихая строка кэфов одного букмекера (`OddsLine`): «Хозяева 2.10 · Ничья 3.40 · Гости 3.20 · Фонбет · Реклама» (простые слова вместо «П1/П2»; линия — `x12Line`, время снимка — в подсказке); вся строка — переход к букмекеру через `goHref(…, 'main-odds', id)` с `rel=sponsored`, поверх накладки сторис. Без неё с первого экрана к ставке вёл только «Бонус» в шапке — владелец согласился вернуть кэфы одной строкой. В игре и после строки нет (LIVE-кэфы не показываем); статистики, вероятностей, фактов, выводов словами и графиков формы в блоке тоже нет — всё это на странице матча (доматчевые вероятности — с подписью «До матча», в игре — «Сейчас в матче»). Нет данных — нулями не заменяем; 0 : 0 из API — настоящее значение (`visibleStats` прячет пустые строки только в списках статистики). Факты с выборкой (`lib/facts.ts`, считаются в `MatchSummary.facts`) и цвета клубов (`lib/team-colors.ts`) на сайте сейчас не показываются — модули с тестами оставлены.
  - LIVE-кэфы не показываем: в SStats они только у Bet365 (зарубежный букмекер). Легальный источник — PARI (`/Pari/odds/history`, `/Pari/events` в API) — отдельным шагом, вместе с настоящей историей линии по времени.
  - «Подборки» (маленькая подпись 13px, `text-mute`, как «Топ-турниры») — три перехода (`IconPicks`/`IconTile` в `DaySummary.tsx`). Значки — та же система, что у историй: белый знак на цветном диске 40px (`StorySymbol` с ключами `pick-all` — расписание строками, синий; `pick-goals` — ворота и мяч, зелёный; `pick-moves` — стрелки вверх и вниз, янтарный; заливка — `discBackground`). Ниже — про прежние объёмные значки: объёмный значок темы без подложки, в настоящих цветах (та же «надутая» серия, что у кружков историй; владелец сгенерировал в ChatGPT: «Все матчи» — зелёное поле с разметкой, «Голевые матчи» — мяч в сетке ворот, «Движение коэффициентов» — стрелки, вверх белая, вниз янтарная, как метка «−17%»; `public/story-icons/` — `pitch`, `goal`, `arrows-up-down`; сначала были белые, владелец выбрал цветные — так узнаваемее, белый мяч читался серым пятном; потом календарь и мяч сменили: мяч повторял кружок «Много голов» на том же экране, красный верх календаря спорил с LIVE; 40px, при наведении чуть крупнее), название с тихой стрелкой и одна строка по делу с настоящими количествами; вся плитка — ссылка. «Все матчи» («31 матч · 6 LIVE», «29 матчей · первый в 13:00», «все сыграны») → список дня `#matches`; «Голевые матчи» («2 матча с шансом от 55%») → `/matches/[date]/goals`; широкий «Движение коэффициентов» (эмблемы матча и исход на всю ширину, справа от названия «10.62 → 8.80» и метка «−17%»: упал — янтарь, вырос — серый; букмекер и период — в подсказке, графика нет) → `/matches/[date]/odds`. Ряд 1 : 1 : 1,6 (а не 1 : 1 : 2 — строкам маленьких плиток нужно место), высота 78px; без обводки: фон светлее страницы (`bg-panel-2`, при наведении — `bg-panel-3`), прозрачная рамка остаётся для режима высокой контрастности. Нет линии — простые слова («Линия ещё загружается», «Заметных изменений линии нет»), без выдуманных цифр. Прежние варианты — плитки из строк текста («стрёмно»), «Цифры дня» с крупными цифрами, плитки с подписью-повтором, квадратом со стрелкой и серыми полосками — владелец заменил этим.
  - Линия одного букмекера (`lib/lines.ts`): все цифры блока и подборок — по одному легальному партнёру (первый из `PARTNERS`, у кого есть нужный рынок; порядок — PARTNERS_ORDER) и одному снимку линии; зарубежных букмекеров по имени не показываем. Снимок — `getOddsSnap` (`/Odds/{id}` и `at` — когда мы взяли линию: своего времени у доматчевых кэфов SStats нет; после начала матча API отдаёт закрытие). Шанс 3+ голов — `goalsLine`: (1/ТБ) / (1/ТБ + 1/ТМ) по паре 2,5 одного букмекера, средние голы команд его не подменяют. Движение — `lineMoves`: открытие → последнее значение по исходам 1X2 и тоталу 2,5, период — `periodText` («с открытия линии до 19:30» / «до начала матча»); кривую между точками не рисуем.
  - Страницы подборок — `app/matches/[date]/goals` и `app/matches/[date]/odds`: шапка с датой и «как считаем», вкладки дня ведут на ту же подборку (`DateTabs section`), фильтры ссылками без JS (`?min=`, `?st=`, `?top=`, `?sort=`; `?dir=`, `?min=`, `?mk=`, `?st=`, `?top=`; значения по умолчанию в адрес не пишем), таблица для сравнения (на телефоне — карточки), отметка охвата (`Coverage`: «линия есть у N из M матчей»). Линия — `daySnaps`: из кэша сразу, топ-турниры без снимка догружаются (страница подборки ждёт ≤2,5 с, страница дня — ≤1,2 с), остальное — в фоне к следующему открытию.
  - «Проверка шансов» с первого экрана ушла: полный график «давали — сбылось» — на `/about#proverka` (`components/ChanceChart.tsx`: столбик — сбылось, белая черта — давали, монохромно, подсказка при наведении/тапе/стрелках; корзины «около 10% … 90%»). Расчёт — `lib/chance-check.ts` (исходы 1X2 сыгранных «взрослых» матчей, шансы — кэфы перед матчем без маржи, итог — по основному времени; корзина меньше 30 исходов не показывается, всего меньше 300 — графика нет), данные — `getChanceCheck` в `lib/data.ts` (30 дней до сегодня; итоги дня кэшируются отдельно и надолго, `/about` ждёт `peekChanceCheck` не дольше 1,5 с, остальное считает прогрев). Не возвращайте виджет «сколько бы заработали» в рублях: крупное «+8 160 ₽, если ставить по 1000 ₽» читается как «ставки — заработок» (ст. 27 закона «О рекламе»), владелец выбрал проценты; и «Фавориты вчера» (кто выиграл, без сравнения с шансом) — тоже нет.
  - Всё тёмное, цвет — только у цифр и выделенной команды: лайм — выгодно, янтарь — кэф упал, красный — live; текст не мельче 13px, без колец-диаграмм (похожи на значок загрузки). Выбор дня у списка «Все матчи дня» (как и чип в блоке, ведёт на страницу дня): `DateTabs` (Вчера · Сегодня · Завтра · дальше день недели без числа; красная точка у «Сегодня», пока идут матчи — `liveToday` из `DayView`) + календарь `DatePicker` (±1 год / +2 месяца), ведут сразу к списку (`#matches`). Порядок «Все матчи дня» — переключатель «По турнирам / По времени» ссылками `?sort=time` (без JS, canonical прежний; `TimeBlock` — по часам, с турниром в строке); на прошедших днях переключателя нет — там порядок по турнирам, главные результаты первыми.
