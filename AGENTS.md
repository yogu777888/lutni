# tag.bet — заметки для агентов

- Сайт на Next.js 16 (App Router, previous caching model — без `cacheComponents`), Tailwind v4, TypeScript 7.
- Все данные — через `lib/data.ts` (кэш `lib/cache.ts` + лимитер `lib/rate-limit.ts`). Не вызывайте `apiGet` из страниц напрямую: у SStats лимит 30 запросов/мин без ключа.
- Страницы с данными — `dynamic = 'force-dynamic'`; кэширует наш слой данных, а не Next.
- У динамических страниц нет `loading.tsx` намеренно: иначе `notFound()`/`permanentRedirect()` отдают 200 вместо 404/308.
- Цветовой токен фона называется `ink` (не `base`: в Tailwind v4 `text-base` — размер шрифта).
- Партнёрские ссылки — только через `goHref()` → `/go/[slug]` (учёт кликов + subid) и `CtaLink` (rel=sponsored).
- Тексты — по-русски; названия команд в текстах только в именительном падеже («команда «X»»).
- Демо без сети: `SSTATS_MOCK=1` (полосы над шапкой нет — только строка в подвале, `IS_MOCK` в `Footer.tsx`). Проверки: `npm run typecheck`, `npm test`, `npm run build`.
- «Матч в слайдах» (сторис): данные — `lib/story.ts` → `/api/story/[id]`, просмотр и графики — `components/story/`. Ссылки на матч в списках — через `StoryLink` (обычная ссылка для SEO, клик открывает сторис).
- Кружки историй на главной: группы — `lib/story-groups.ts` (порядок по `lib/rank.ts`), ряд — `components/story/StoryCircles.tsx`, очередь передаётся в просмотрщик через `openStory({ queue })`. Просмотренные — в `localStorage` (`components/story/seen.ts`, ключ `tagbet:seen:v2`), только для колец и отдельно для каждого кружка (отметка «кружок:матч»): просмотр в одном кружке не гасит другие, открытия из списков и виджетов не считаются; сегменты гаснут по порядку от верха. Очередь по тапу и отметки повторов — `components/story/queue.ts` (тест `tests/story-queue.test.ts`). На главной — «#в игре», «#топ дня» и до 5 главных тегов (`mainCircles`), подписи в одну строку; хештег — у всех кружков, и у подборок тоже (владельцу показалось странным, что «Топ дня» без него).
- «Сводка дня» (виджеты первого экрана главной): данные — `lib/day-summary.ts` (`buildDaySummary`: матч дня и подборки `lists` — live, ближайшие, фавориты от 60%, голы, выгодные, падение кэфа; матч дня в подборках не повторяется; `summaryCards` — какие 4 плитки показать: что идёт (или скоро начнётся) → фавориты → голы → выгодно, запасные — кэф упал, ближайшие, турниры дня), вид — `components/DaySummary.tsx`. «Матч дня» — `components/TopCarousel.tsx` (клиент): по слайду на главный матч каждой топ-лиги (`tops` в `buildDaySummary`, до 5, первым — матч дня); лига выбирается чипом-меню «Ла Лига ▾» справа сверху, сама карточка не листается (выбор не должен уезжать); лента со scroll-snap — свайп на телефоне, без JS видны все слайды. На «Сегодня» рядом — аналитика «Фавориты вчера · как сыграли» (`favoritesRecap` в `lib/day-summary.ts`, `RecapTile`): «7 из 12 выиграли», одна сегментная полоса «победы · ничьи · сенсации» с подписью словами и строки сенсаций (матч, счёт, шанс фаворита) — та же схема строк, что у подборок; не возвращайте столбиковую диаграмму без подписей — владелец счёл её странной; тёмная, во всю высоту, на месте двух плиток — подборок справа тогда две. На компьютере слева высокий «Матч дня»: команды и время начала справа, как на табло (в игре — счёт; «через 40 мин» — от sm), вывод словами и нейтральная полоса шансов в процентах с подписями «команда · Ничья · команда» (светлая — фаворит), до трёх фактов «почему» из тегов (значки — как у кружков этих тегов; третий — только при высоте окна от 780px), «Разбор за минуту» и «Выгодно». Справа — до 4 плиток-подборок 2×2: каждая отвечает на один вопрос несколькими матчами — заголовок с вопросом и что значит цифра («Фавориты · шанс победы», «Ждём голов · шанс 3+ голов»), строки «команды … цифра» (выделенная команда — ярче или цветом подборки), строка открывает сторис, заголовок со стрелкой `Go` — страницу тега или список матчей. Строки делят высоту плитки поровну (пустот нет); четвёртая — только на lg при высоте окна от 760px. Не возвращайте плитки «одна крупная цифра + один матч» — владелец счёл их неинформативными; и не убирайте «Матч дня» — без него сводка («Главное за день») не понравилась. Всё тёмное, цвет — только у цифр и выделенной команды: лайм — выгодно, янтарь — кэф упал, красный — live; текст не мельче 13px, без колец-диаграмм (похожи на значок загрузки). Выбор дня — `DateTabs` (Вчера · Сегодня · Завтра · дальше день недели без числа; красная точка у «Сегодня», пока идут матчи — `liveToday` из `DayView`) + календарь `DatePicker` (±1 год / +2 месяца). Порядок «Все матчи дня» — переключатель «По турнирам / По времени» ссылками `?sort=time` (без JS, canonical прежний; `TimeBlock` — по часам, с турниром в строке); на прошедших днях переключателя нет — там порядок по турнирам, главные результаты первыми. Первый экран главной (шапка, кружки, сводка) на компьютере занимает всё окно: обёртка в `DayView` — `lg:min-h-[min(calc(100svh-7rem),50rem)]`, сводка — `lg:flex-1`, команды и вывод «Матча дня» растут с высотой окна (`clamp(…vh…)`), а «Все матчи дня» начинаются ниже, по прокрутке. Сводка должна влезать целиком в 1280×720 и 1440×760, а заголовок «Матчи» — не выглядывать снизу; проверяйте замером. На прошедших днях сводки нет.
- Шапка (логотип — только наклонная лаймовая решётка `LogoMark`, 26 px в шапке и 28 в подвале, без надписи «tag.bet» — так решил владелец; знак — `components/logo-paths.ts` из `public/brand/mark.svg`; без подложки): `components/Header.tsx` + `HeaderShell.tsx` (стекло после прокрутки) + `NavCapsule.tsx` (меню-капсула; раздел по адресу — `activeNav`).
- Кнопки и чипы внутри карточек (чип лиги, стрелка `Go`, «Разбор за минуту», «Выгодно») — скруглённые прямоугольники (углы 9–10px, меню — 14px), мягкая заливка без обводки; капсулой остаётся только меню в шапке.
- Цвета по смыслу: лайм — «цена выше честной» (сила перевеса — яркостью лайма, `edgeTone` в `components/Flaps.tsx`), янтарь — прогруз, красный — live. Светофор не используем.
- Для тех, кто не разбирается в цифрах: вывод словами — `lib/verdict.ts` (`buildVerdict`: «Скорее выиграет «X»», голы, падение кэфа, выгодная ставка; `split100` — проценты трёх исходов в сумме ровно 100, `outcomeText`/`outcomeShort` — исход словами вместо «П1»/«ТБ 2.5»). Только факты из данных: про прогруз — «кэф снизился», не «массово ставят». Пороги слов — как у тега #фаворит (60%) и слайда «Кто фаворит» (47%). Без обещаний: только «скорее», «вероятно». В строках и «Матче дня» — только выгодная ставка (обычный прогноз модели бывает «против» вывода). Теги подписаны простыми словами (`label`: `#выгодно`, `#кэф упал`…), slug и адреса прежние; цифра тега — в `TagHit.p`, а не в тексте.
- Обложки кружков историй: плоские, как карточки — заливка `CIRCLE_BG` (= `--color-panel`), тонкая рамка `ring-edge`, светлая иконка тега без теней, бликов и зерна (владелец счёл «стеклянный» вид чужим); кружка «Все теги» нет — в ряду только истории, «Теги» есть в шапке. Иконка тега — `lib/story-art.ts` + `components/story/ArtIcon.tsx` (цвет — только в кольце: лайм не смотрели, красный LIVE, серый просмотрено; цвета тегов `ART` — только для фона просмотрщика); своя картинка — файл `public/stories/<ключ>.*` (`lib/story-covers.ts`, только сервер). Цифр в кружках нет.
