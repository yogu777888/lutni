# tag.bet — заметки для агентов

- Сайт на Next.js 16 (App Router, previous caching model — без `cacheComponents`), Tailwind v4, TypeScript 7.
- Все данные — через `lib/data.ts` (кэш `lib/cache.ts` + лимитер `lib/rate-limit.ts`). Не вызывайте `apiGet` из страниц напрямую: у SStats лимит 30 запросов/мин без ключа.
- Страницы с данными — `dynamic = 'force-dynamic'`; кэширует наш слой данных, а не Next.
- У динамических страниц нет `loading.tsx` намеренно: иначе `notFound()`/`permanentRedirect()` отдают 200 вместо 404/308.
- Цветовой токен фона называется `ink` (не `base`: в Tailwind v4 `text-base` — размер шрифта): графит `#0B0F14` (текст на лаймовых кнопках, стекло шапки); фон страницы — `#090C10` на `body`.
- **Строка матча — одна схема у всех строк** (владелец: «криво — время везде по-разному, кэфы не везде есть, счёт не везде есть»; `MatchRow`): время · матч · счёт · кэфы в каждой строке. Время — одной строкой одного размера (15px): начало / «● 59′» красным; у сыгранных — время начала серым, текст команд и счёт обычные, тусклее только проигравший (всю строку серой владелец попробовал и попросил вернуть; пустая колонка, которую владелец просил сначала, выглядела как «не загрузилось»; «итог» — только для экранного диктора). Счёт — у начавшихся на одном месте во всех блоках; до начала место пустое (тихое «– : –» владелец попросил убрать). Кэфы — только до начала (выгодный — лаймовой ячейкой, без подписи — владелец: «а выгодно тоже убрать?»; объяснение — только в подсказке ячейки; строку-пояснение внизу блока владелец тоже попросил убрать); у идущих и сыгранных кэфов нет — место колонки пустое той же высоты (владелец: «а кэфы у сыгранных может вообще убрать?», «у идущих может тоже убрать?»); колонки у всех блоков списка одни и те же (счёт на одной вертикали и в «Сейчас в игре»), шапки нет, если в блоке нет не начавшихся с линией (`anyOdds`). Шапки колонок нет (владелец: «а шапку колонок может тоже убрать?»): порядок кэфов — хозяева · ничья · гости, у ячейки подсказка «Победа «X»» / «Ничья». На телефоне — команды в две строки, справа счёт, кэфы ниже. Время слева (начало / минута) — тоже Oswald, 18px (владелец: «время шрифтом Oswald тоже надо?»); кэфы — Onest. Строка на компьютере — 54px (отступ 10px сверху и снизу; было 12px — после чистки строка однострочная, владелец: «отступы между строками уменьшить?»). Счёт в строке — Oswald 24px (`display-num`, как в «Матче дня»; владелец: «счёт шрифтом Oswald надо?»). Заголовки блоков (лига, «Сейчас в игре», «Другие турниры») — 20px (были 17px — почти как названия команд 16px; владелец: «заголовок лиги покрупнее?»). В «Сейчас в игре» турнира под командами нет (владелец: «а турнир под командами в лайве убрать?»); в списке «По времени» — остался. Ниже — про строки без кэфов у начавшихся и подпись под командами — история.
- **Строка матча — одно правило на состояние** (владелец: «в центральных блоках логическая каша написана почти везде»; `MatchRow` в `components/MatchRow.tsx`): до начала — кэфы, а подпись под командами — только у выгодной ставки (лаймом «Выгодно: победа «X»» — объясняет лаймовую ячейку); «кто сильнее» словами в строке не пишем (владелец: «а подпись под командами тоже убрать?» — это видно по кэфам); полосы шансов нет (владелец: «а полосу шансов может тоже убрать?» — она повторяла подпись словами); идёт и сыгран — только счёт (минута / «итог» слева), без доматчевых кэфов и без тегов.
